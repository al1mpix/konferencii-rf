# Конференции.РФ

**Выполнил:** Гришин Владислав Игоревич, группа 492  
**Проверил:** преподаватель Денис Спиридонов Сергеевич

Учебное веб-приложение для бронирования помещений для конференций.

**Стек:** PHP 8.2+, Laravel 12, MySQL, Blade, HTML, CSS.  
**Макет Figma:** https://www.figma.com/design/hk7zuPMx31Y5Anm9ebYxoV

## Возможности

- Регистрация с валидацией и проверкой уникальности логина/email.
- Авторизация пользователей по логину и паролю.
- Создание заявки с помещением, датой мероприятия и способом оплаты.
- Личный кабинет с просмотром только своих заявок.
- Отзыв доступен только после статуса «Завершено».
- Панель администратора с поиском и фильтрацией заявок, изменением статуса.
- Адаптивные Blade-представления для мобильного и настольного экранов.

## Что важно показать на защите

- **Миграции:** database/migrations/0001_01_01_000000_create_users_table.php и database/migrations/0001_01_01_000001_create_bookings_table.php.
- **Модели:** app/Models/User.php и app/Models/Booking.php. User связан с заявками через hasMany, Booking с пользователем через belongsTo.
- **Контроллеры:** AuthController, BookingController, AdminController.
- **Представления Blade:** resources/views/.
- **Маршруты:** routes/web.php.
- **Проверка администратора:** app/Http/Middleware/AdminMiddleware.php.

## Установка и запуск

Нужны PHP 8.2+, Composer, MySQL и расширение PHP pdo_mysql.

1. Создайте в MySQL базу данных с именем konferencii_rf, кодировка utf8mb4.
2. Скопируйте .env.example в .env.
3. Укажите настройки подключения к MySQL в .env.
4. Установите пакеты и создайте ключ приложения:

    composer install
    php artisan key:generate

5. Выполните миграции и запустите встроенный сервер:

    php artisan migrate
    php artisan serve

6. Откройте http://127.0.0.1:8000.

В Windows PowerShell скопировать конфигурацию можно командой Copy-Item .env.example .env. В macOS/Linux: cp .env.example .env.

## Структура проекта

    app/Models/              Eloquent-модели User и Booking
    app/Http/Controllers/    контроллеры авторизации, заявок и администратора
    app/Http/Middleware/     проверка доступа администратора
    database/migrations/     схема таблиц users и bookings
    database/seeders/        точка входа для учебного наполнения БД
    resources/views/         Blade-представления сайта
    routes/web.php           веб-маршруты
    public/css/app.css       адаптивные стили
    config/database.php      подключение к MySQL
    docs/                    документация, ER-диаграмма, вопросы к защите

## Структура базы данных

- users: ФИО, уникальный логин, телефон, уникальный email, хеш пароля, даты создания и изменения.
- bookings: внешний ключ пользователя, помещение, дата события, способ оплаты, статус, отзыв, даты создания и изменения.

Один пользователь может иметь несколько заявок. Поле bookings.user_id ссылается на users.id. ER-диаграмма находится в docs/ERD.svg.

Проект предназначен для учебного запуска. Перед публикацией необходимо настроить уникальные значения окружения, убедиться, что APP_DEBUG=false, добавить дополнительные меры защиты и проверить приложение в целевой среде.
