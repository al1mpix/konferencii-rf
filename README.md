# Конференции.РФ

**Выполнил:** Гришин Владислав Игоревич, группа 492  
**Проверил:** преподаватель Денис Спиридонов Сергеевич

Учебное веб-приложение для оформления и администрирования заявок на бронирование помещений для конференций. Реализованы регистрация, авторизация, личный кабинет, создание заявки, администраторский поиск и управление статусами.

**Figma:** https://www.figma.com/design/hk7zuPMx31Y5Anm9ebYxoV

## Технологии

- Python 3.10+
- Flask и Jinja2 — серверная логика и HTML-шаблоны
- SQLite — хранение пользователей и заявок
- HTML, CSS и JavaScript — интерфейс и адаптивность
- Werkzeug — хеширование и проверка паролей

## Запуск локально

### Windows (PowerShell)

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

После запуска откройте http://127.0.0.1:5000. При первом запуске создаётся база `conference.db`.

## Функциональность

- Регистрация с проверкой формата полей и уникальности логина.
- Вход пользователя и администратора.
- Создание заявки с выбором помещения, даты и способа оплаты.
- Личный кабинет для просмотра своих заявок.
- Отзыв доступен только после завершения мероприятия.
- Панель администратора: просмотр заявок, поиск по ФИО/логину/помещению, фильтр по статусу и изменение статуса.
- Адаптивная раскладка для мобильных экранов.

## База данных

База содержит две основные таблицы:

- `users`: логин, хеш пароля, ФИО, телефон, email и дата создания.
- `bookings`: владелец заявки, помещение, дата мероприятия, способ оплаты, статус, отзыв и дата создания.

Связь: `bookings.user_id` ссылается на `users.id`. Один пользователь может иметь несколько заявок. Диаграмма: [docs/ERD.svg](docs/ERD.svg).

## Проверка основных сценариев

1. Создать обычного пользователя и войти в систему.
2. Создать заявку и убедиться, что она появляется в личном кабинете со статусом «Новая».
3. Войти как администратор и найти заявку.
4. Изменить статус на «Мероприятие назначено», затем на «Завершено».
5. Вернуться в личный кабинет и проверить доступность отзыва.

## Ограничения учебной версии

Приложение предназначено для локального учебного запуска. Перед публичным развёртыванием необходимо установить уникальный `SECRET_KEY` через переменную окружения, отключить `debug`, добавить CSRF-защиту и хранить административные учётные данные в защищённой конфигурации. Файл БД, виртуальное окружение и секреты исключены из Git через `.gitignore`.
