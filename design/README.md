# Дизайн-материалы «Конференции.РФ»

**Выполнил:** Гришин Владислав Игоревич, группа 492  
**Проверил:** преподаватель Денис Спиридонов Сергеевич

Визуальная концепция описана в ../docs/Концепция-дизайна.md, адаптивные стили Laravel 10-приложения лежат в ../public/css/app.css, представления Blade находятся в ../resources/views/.

Вспомогательный скрипт generate_mockups.py генерирует отдельные демонстрационные PNG-макеты. Для его запуска потребуется Python и Pillow:

    python -m pip install Pillow
    python design/generate_mockups.py

Изображения сохраняются в design/exports/. Скрипт предназначен только для создания графических превью; он не является частью серверного приложения Laravel.
