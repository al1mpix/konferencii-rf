# Дизайн-макеты «Конференции.РФ»

Веб-приложение имеет адаптивные стили для домашней страницы, авторизации, регистрации, создания заявки, личного кабинета и панели администратора.

## Генерация демонстрационных PNG-макетов

Скрипт `generate_mockups.py` генерирует макеты для шести экранов в двух форматах:
- десктоп: 1440×1024 px;
- мобильный: 390×844 px.

Для запуска генератора дополнительно установите Pillow:

```bash
python -m pip install Pillow
python design/generate_mockups.py
```

Файлы PNG будут сохранены в папку `design/exports`.

## Визуальная система

Палитра и правила оформления веб-приложения описаны в `../docs/Концепция-дизайна.md`. Ссылка на онлайн-проект Figma находится в основном README. Отдельный комплект SVG-макетов для импорта в Figma и экспортированные изображения передаются вместе с архивом материалов сдачи.
