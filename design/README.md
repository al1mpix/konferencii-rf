# Дизайн-макеты «Конференции.РФ»

В проектной папке `design` собраны материалы дизайн-концепции. В веб-приложении используются адаптивные CSS-стили для домашней страницы, авторизации, регистрации, создания заявки, личного кабинета и панели администратора.

## Визуальная система рабочей версии

Основные цвета и шрифты описаны в `docs/Концепция-дизайна.md`. В `figma_import` хранятся SVG-экраны для импорта и дальнейшей настройки в Figma. В задании отдельно требуются экспортированные изображения страниц, UI-кит, компоненты, исходники GIMP и прототип с переходами. Эти пункты необходимо сверить с фактически подготовленными материалами перед сдачей.
