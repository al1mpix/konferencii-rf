## 1. Назначение проекта

«Конференции.РФ» — учебное веб-приложение для подачи заявок на бронирование помещений под конференции. Пользователь создаёт аккаунт, выбирает помещение, указывает дату мероприятия и способ оплаты. Администратор рассматривает заявки и меняет их статусы. После завершения мероприятия пользователь может оставить отзыв.

## 2. Технологический стек

- PHP 8.1+
- Laravel 10 — MVC-фреймворк.
- MySQL — реляционная база данных.
- Eloquent ORM — работа с таблицами через модели.
- Blade — серверные HTML-представления.
- HTML/CSS — интерфейс и адаптивная вёрстка.

## 3. Архитектура MVC

- **Model (модель)** описывает данные и связи с базой. Файлы: app/Models/User.php, app/Models/Booking.php.
- **View (представление)** отвечает за отображение страниц. Файлы находятся в resources/views/ и используют Blade.
- **Controller (контроллер)** принимает запрос, проверяет входные данные и выбирает дальнейшее действие. Контроллеры находятся в app/Http/Controllers/.
- **Route (маршрут)** связывает URL и HTTP-метод с контроллером или представлением. Файл: routes/web.php.
- **Middleware** выполняет проверку доступа до запуска контроллера. AdminMiddleware защищает административные маршруты.

| / | GET | Приветственная страница |

## 5. Миграции базы данных

Миграции располагаются в database/migrations/. Миграция — версия схемы БД, описанная кодом PHP. Метод up() создаёт или изменяет таблицы; down() отменяет изменение.

### Таблица users

| Поле | Тип / назначение |
|---|---|
| id | Первичный ключ |
| full_name | ФИО пользователя |
| login | Логин, уникальный индекс |
| phone | Контактный телефон |
| email | Адрес электронной почты, уникальный индекс |
| password | Хеш пароля |
| remember_token | Токен для опции «Запомнить меня» |
| created_at, updated_at | Даты создания и изменения |

### Таблица bookings

| Поле | Тип / назначение |
|---|---|
| id | Первичный ключ |
| user_id | Внешний ключ на users.id |
| room | Тип помещения |
| event_date | Дата мероприятия |
| payment | Способ оплаты |
| status | Статус, по умолчанию «Новая» |
| review | Отзыв, допускается NULL |
| created_at, updated_at | Даты создания и изменения |

Внешний ключ user_id объявлен через foreignId()->constrained()->cascadeOnDelete(). Удаление пользователя удаляет и его заявки. Для статуса и даты мероприятия созданы индексы.

Команды управления схемой:

    php artisan migrate
    php artisan migrate:status
    php artisan migrate:rollback

## 6. Модели Eloquent и связи

### User

Модель наследуется от Illuminate\Foundation\Auth\User, поэтому поддерживает стандартную сессию аутентификации Laravel. Поле fillable разрешает массовое заполнение только перечисленных полей. Пароль скрыт при сериализации.

Метод bookings(): HasMany описывает связь **один ко многим**: у одного пользователя может быть несколько заявок.

### Booking

Модель описывает заявку. Константы ROOMS, PAYMENTS и STATUSES задают разрешённые значения в интерфейсе и контроллерах.

Метод user(): BelongsTo описывает обратную связь: заявка принадлежит одному пользователю. Метод isCompleted() используется для проверки, завершено ли мероприятие.

## 7. Контроллеры

### AuthController

showLogin() и showRegister() показывают формы. register() валидирует данные, хеширует пароль, создаёт пользователя и авторизует его. login() проверяет демонстрационные данные администратора или вызывает Auth::attempt() для обычного пользователя. logout() завершает сессию.

### BookingController

index() загружает заявки только текущего пользователя. create() подготавливает список помещений, способов оплаты и минимальную дату. store() валидирует форму и создаёт заявку со статусом «Новая». review() проверяет владельца заявки и требует статус «Завершено» перед сохранением отзыва.

### AdminController

index() загружает заявки вместе с данными пользователей через with('user'). Поиск применяется по помещению, ФИО, логину и email; фильтр ограничивает результаты выбранным статусом. updateStatus() проверяет новый статус и сохраняет его.

## 8. Представления Blade

Blade-шаблоны располагаются в resources/views/:

- layouts/app.blade.php — общий каркас, навигация и сообщения.
- home.blade.php — приветственная страница.
- auth/login.blade.php — вход.
- auth/register.blade.php — регистрация.
- bookings/create.blade.php — создание заявки.
- bookings/index.blade.php — личный кабинет пользователя.
- admin/index.blade.php — панель администратора.

Blade-директивы @extends, @section, @foreach, @if, @csrf и @method помогают повторно использовать общий шаблон, выводить данные и защищать формы от CSRF. Значения {{ ... }} экранируются при выводе.

## 9. Валидация и бизнес-правила

- Логин: латинские буквы и цифры, от 6 символов, уникальный.
- Пароль: от 8 символов, подтверждается повторным вводом.
- ФИО: кириллица, пробелы и дефисы.
- Телефон: 8(XXX)XXX-XX-XX.
- Email: корректный формат, уникальное значение.
- Помещение и способ оплаты должны быть выбраны из допустимых списков.
- Дата конференции — сегодня или позже.
- Новый запрос получает статус «Новая».
- Пользователь может видеть и оценивать только принадлежащие ему заявки.
- Отзыв доступен только после статуса «Завершено».
- Административные маршруты закрыты middleware admin.

## 10. Настройка и запуск

Требуются PHP 8.1+, Composer, MySQL и PHP-расширение pdo_mysql.

1. Создать базу данных konferencii_rf в MySQL с кодировкой utf8mb4.
2. Создать .env из .env.example.
3. Указать DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME, DB_PASSWORD.
4. Выполнить:

    composer install
    php artisan key:generate
    php artisan migrate
    php artisan serve

Открыть http://127.0.0.1:8000.

## 11. Учебный доступ администратора

Настройки ADMIN_LOGIN и ADMIN_PASSWORD в .env используются для демонстрационного входа. Значения по умолчанию: Conf2027 / Demo77. Для реальной эксплуатации их нужно заменить и хранить вне исходного кода.
