# Концепция дизайна

Проект «Конференции.РФ» предназначен для бронирования помещений для проведения конференций. Интерфейс организован так, чтобы пользователь мог быстро выбрать формат пространства, отправить заявку и затем следить за её статусом.

## Визуальная система веб-приложения

- Основной сине-графитовый цвет: `#285779`.
- Дополнительный синий: `#39749a`.
- Терракотовый акцент: `#e8a06a`.
- Светлый тёплый фон: `#f6f4ef`.
- Основной текст: `#1d2b3a`, вторичный текст: `#68727d`.
- Georgia используется для крупных заголовков, Arial — для основного текста, навигации и форм.
- Кнопки и поля имеют умеренные скругления, тонкие границы и минимум теней.

## Структура страниц

1. Приветственная страница объясняет назначение сервиса и показывает типы помещений.
2. Авторизация содержит поля логина и пароля, а также подсказку для входа администратора.
3. Регистрация содержит обязательные поля и краткие подсказки по форматам.
4. Создание заявки позволяет выбрать помещение, дату и способ оплаты.
5. Личный кабинет показывает заявки пользователя и даёт оставить отзыв после завершения мероприятия.
6. Панель администратора показывает все заявки, поиск, фильтр по статусу и управление статусами.

## Адаптивность и удобство

На широком экране используется многоколоночная раскладка. На мобильных ширинах содержимое перестраивается в одну колонку, а формы становятся шириной контейнера. Основные действия вынесены на заметные кнопки, поля снабжены подписями, а сообщения об ошибках и успехе выводятся рядом с основным содержимым.

## Что проверить перед сдачей

- Макеты и рабочие страницы должны иметь согласованную палитру и шрифты.
- Основные кнопки и подписи должны оставаться читаемыми.
- Статусы заявок должны различаться.
- На мобильном экране элементы не должны выходить за границы.
- Нужно приложить отдельные экспорты и источники изображений, предусмотренные заданием.
