## Как коротко представить работу

«Я разработал на Laravel 10 веб-приложение для бронирования помещений под конференции. Данные хранятся в MySQL. В проекте использованы миграции для схемы базы, модели Eloquent для сущностей пользователя и заявки, контроллеры для бизнес-логики и Blade-представления для интерфейса».

## 1. Что такое MVC?

MVC делит приложение на три основные части:
- Model отвечает за данные и связи с базой.
- View отображает интерфейс.
- Controller принимает запросы, валидирует их и связывает модели с представлениями.

В проекте: User и Booking — модели; каталог resources/views — представления; AuthController, BookingController, AdminController — контроллеры.

## 2. Что такое миграция?

Миграция — версия структуры базы данных, записанная в PHP-коде. В up() описывается создание таблицы и полей, в down() — отмена. Запустить миграции можно командой php artisan migrate, посмотреть статус — php artisan migrate:status.

## 3. Какие таблицы в MySQL?

- users — сведения о пользователях и хеши паролей.
- bookings — заявки на помещение, дата, способ оплаты, статус и отзыв.

bookings.user_id — внешний ключ на users.id.

## 4. Что такое модель Eloquent?

Модель Eloquent — PHP-класс, который представляет сущность в таблице и предоставляет методы запросов к БД. Например, Booking::query()->latest() начинает запрос к таблице заявок.

## 5. Какие связи определены?

В User метод bookings() возвращает hasMany(Booking::class): один пользователь может иметь несколько заявок. В Booking метод user() возвращает belongsTo(User::class): каждая заявка принадлежит одному пользователю.

## 6. Что делают контроллеры?

- AuthController: регистрация, вход и выход.
- BookingController: создание и просмотр собственных заявок, отзывы.
- AdminController: список заявок, фильтр, поиск и смена статуса.

## 7. Что такое Blade?

Blade — шаблонизатор Laravel. @extends подключает общий layout, @section задаёт содержимое страницы, @foreach перебирает коллекции, @if отображает условные блоки, {{ $value }} выводит экранированное значение, @csrf вставляет CSRF-токен.

## 8. Как работает регистрация?

1. Форма отправляет POST-запрос на /register.
2. Контроллер проверяет входные поля через $request->validate().
3. Hash::make() хеширует пароль.
4. User::create() сохраняет нового пользователя.
5. Auth::login($user) создаёт авторизованную сессию.

## 9. Как устроена авторизация?

Для обычного пользователя используется Auth::attempt() с логином и паролем. Laravel сверяет предоставленный пароль с хешем в БД. После входа сессия регенерируется.

Для учебного администратора предусмотрены переменные окружения ADMIN_LOGIN и ADMIN_PASSWORD; при успешном входе включается флаг is_admin в сессии.

## 10. Зачем AdminMiddleware?

Middleware проверяет session('is_admin') до входа в административный контроллер. Если флаг отсутствует, пользователь перенаправляется на страницу входа и не получает доступ к панели.

## 11. Как создаётся заявка?

BookingController::store() валидирует помещение, дату и способ оплаты. Затем текущий пользователь создаёт заявку через отношение bookings(). Статус первоначально «Новая».

## 12. Почему пользователь не видит чужие заявки?

В BookingController::index() запрос запускается через отношение текущего пользователя: Auth::user()->bookings(). В методе отзыва дополнительно проверяется, что booking.user_id равен Auth::id().

## 13. Как работает поиск администратора?

AdminController::index() строит запрос Booking::query()->with('user'), затем при наличии строки поиска добавляет where и orWhereHas('user', ...), фильтрует по выбранному статусу и возвращает пагинированный список.

## 14. Когда можно оставить отзыв?

Только после завершения мероприятия. Проверка isCompleted() выполняется на сервере; скрытия формы на странице недостаточно, потому что запрос можно отправить вручную.

## 15. Как запустить проект?

1. Установить PHP 8.2+, Composer и MySQL.
2. Создать БД konferencii_rf.
3. Скопировать .env.example в .env и заполнить параметры MySQL.
4. Выполнить composer install.
5. Выполнить php artisan key:generate.
6. Выполнить php artisan migrate.
7. Запустить php artisan serve и открыть http://127.0.0.1:8000.

## Короткие определения

- **Маршрут:** сопоставляет URL и HTTP-метод с действием приложения.
- **Валидация:** проверяет, что ввод соответствует правилам до записи в БД.
- **ORM:** слой, который даёт работать с таблицами через PHP-объекты.
- **Хеш пароля:** одностороннее преобразование пароля; исходный пароль не хранится напрямую.
- **Внешний ключ:** ограничение, которое связывает запись одной таблицы с записью другой.
